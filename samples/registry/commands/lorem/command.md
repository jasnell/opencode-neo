description: "Quick-generate lorem ipsum placeholder text"
---

Generate lorem ipsum placeholder text.

If the user provided a number as the first argument, generate that many
paragraphs. Otherwise default to 3 paragraphs.

Number of paragraphs requested: $1

Use the lorem-generate tool if it's available, otherwise generate the
text directly following these guidelines:

- Start the first paragraph with "Lorem ipsum dolor sit amet..."
- Use 4-6 sentences per paragraph
- Vary sentence length for natural rhythm
- Separate paragraphs with blank lines

Output the text in plain format unless the user specified otherwise in
their arguments: $ARGUMENTS
