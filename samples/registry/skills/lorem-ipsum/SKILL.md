# Lorem Ipsum

You now understand lorem ipsum placeholder text and how to use it effectively.

## Background

Lorem ipsum is derived from Cicero's "De Finibus Bonorum et Malorum" (45 BC),
section 1.10.32. The standard passage has been used as typesetting placeholder
text since the 1500s. It is intentionally nonsensical Latin so it doesn't
distract from visual design.

## The Standard Passage

The canonical lorem ipsum text begins:

> Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod
> tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam,
> quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo
> consequat.

## When to Use Lorem Ipsum

- **UI mockups**: Fill text areas, cards, and lists with realistic-length content
- **Design reviews**: Show how layouts handle varying text lengths
- **Documentation templates**: Placeholder for sections not yet written
- **Test data**: Generate content for automated tests that need string fields
- **Email templates**: Fill body content during template development

## When NOT to Use Lorem Ipsum

- Final production content -- always replace before shipping
- Accessibility testing -- use real language to test screen readers
- Content strategy work -- use representative real copy instead
- Internationalization testing -- use actual translated strings

## Generating Variants

When generating placeholder text, vary the output:

- **Short**: 1-2 sentences for labels, titles, subtitles
- **Medium**: 1-2 paragraphs for card content, descriptions, summaries
- **Long**: 3-5 paragraphs for article bodies, documentation sections
- **Structured**: Mix headings, lists, and paragraphs for rich content areas

Always match the approximate length and structure of what the real content
will look like. A product description placeholder should be product-description
length, not an essay.

## Style Guidelines

When asked to generate lorem ipsum or placeholder text:

1. Start with the traditional "Lorem ipsum dolor sit amet" for the first paragraph
2. Use varied sentence lengths (mix short and long)
3. Include paragraph breaks at natural points
4. If generating structured content, use realistic heading patterns
5. For lists, vary item lengths (not all the same word count)
